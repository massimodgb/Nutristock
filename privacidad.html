NutriStock · Política de privacidad

NutriStock es una aplicación de uso personal para llevar la alimentación, la despensa y el entrenamiento.

  • Los datos se guardan en el propio dispositivo y, si el usuario inicia sesión, en una base de datos privada (Supabase) a la que solo accede su propia cuenta.
  • Si el usuario conecta Whoop, la app lee únicamente sus datos de recuperación, ciclos, sueño, entrenamientos, perfil y medidas corporales, para mostrárselos y cruzarlos con su alimentación.
  • Los datos no se venden, no se comparten con terceros y no se usan para publicidad.
  • El usuario puede desconectar Whoop y borrar sus datos en cualquier momento.
